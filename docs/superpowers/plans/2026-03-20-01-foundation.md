# Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up the Next.js project, database schema, authentication, and admin layout — the foundation everything else builds on.

**Architecture:** Next.js 14 App Router with PostgreSQL via Prisma ORM. NextAuth.js GitHub OAuth for admin-only auth. Tailwind CSS for styling with a dark + warm theme. The existing static HTML files (`index.html`, `form.html`, `style.css`, `script.js`) will be preserved at the project root but are not used by the Next.js app.

**Tech Stack:** Next.js 14, TypeScript, PostgreSQL, Prisma, NextAuth.js, Tailwind CSS, Vercel Blob

**Spec:** `docs/superpowers/specs/2026-03-20-build-in-public-platform-design.md`

**Subsequent plans:** Members & Profiles, Content Curation, Activity Feeds, Learning Tracks, Events & Homepage, Visual Polish

### Task 4: Set Up NextAuth with GitHub OAuth

- [ ] **Step 2: Create the NextAuth config**

Create `src/lib/auth.ts`:

```typescript
import { NextAuthOptions } from "next-auth";
import GitHubProvider from "next-auth/providers/github";
import { prisma } from "./prisma";

export const authOptions: NextAuthOptions = {
  providers: [
    GitHubProvider({
      clientId: process.env.GITHUB_ID!,
      clientSecret: process.env.GITHUB_SECRET!,
    }),
  ],
  callbacks: {
    async signIn({ profile }) {
      if (!profile?.login) return false;

      const member = await prisma.member.findFirst({
        where: {
          platformLinks: {
            path: ["github"],
            equals: profile.login,
          },
        },
      });

      return member?.role === "admin";
    },
    async session({ session, token }) {
      if (token.sub) {
        const member = await prisma.member.findFirst({
          where: {
            platformLinks: {
              path: ["github"],
              equals: token.githubUsername,
            },
          },
        });

        if (member) {
          session.user.memberId = member.id;
          session.user.role = member.role;
          session.user.slug = member.slug;
        }
      }
      return session;
    },
    async jwt({ token, profile }) {
      if (profile?.login) {
        token.githubUsername = profile.login;
      }
      return token;
    },
  },
  // Uses NextAuth's default /api/auth/signin page.
  // No custom pages — avoids redirect loops with admin middleware.
};
```

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";

const navItems = [
  { href: "/admin", label: "Dashboard", icon: "⌘" },
  { href: "/admin/members", label: "Members", icon: "👥" },
  { href: "/admin/content", label: "Content", icon: "📝" },
  { href: "/admin/integrations", label: "Integrations", icon: "🔗" },
  { href: "/admin/events", label: "Events", icon: "📅" },
  { href: "/admin/learning", label: "Learning", icon: "📚" },
];

export default function Sidebar() {
  const pathname = usePathname();

  return (
    <aside className="w-64 min-h-screen bg-[#0a0a0a] border-r border-white/10 p-6">
      <Link href="/" className="block mb-8">
        <h2 className="text-lg font-bold text-[#fdcb6e]">B&Z Admin</h2>
      </Link>
      <nav className="space-y-1">
        {navItems.map((item) => {
          const isActive =
            item.href === "/admin"
              ? pathname === "/admin"
              : pathname.startsWith(item.href);
          return (
            <Link
              key={item.href}
              href={item.href}
              className={`flex items-center gap-3 px-3 py-2 rounded-lg text-sm transition-colors ${
                isActive
                  ? "bg-white/10 text-[#fdcb6e]"
                  : "text-white/60 hover:text-white hover:bg-white/5"
              }`}
            >
              <span>{item.icon}</span>
              <span>{item.label}</span>
            </Link>
          );
        })}
      </nav>
    </aside>
  );
}
```
